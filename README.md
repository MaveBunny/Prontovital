# Prontovital - Frontend

Este é o repositório frontend para a solução digital de pré-triagem e agendamento de consultas, desenvolvida inicialmente com foco no contexto do polo médico de Recife. O projeto será construído como uma aplicação Web PWA e Mobile.

## 🎯 O Problema

A dificuldade de encontrar o atendimento adequado e realizar um agendamento de forma simples torna a busca por serviços de saúde uma experiência fragmentada e pouco intuitiva para o paciente.

## 💡 A Solução

Uma plataforma que centraliza pré-triagem, orientação, busca e agendamento. O sistema conecta os pacientes à rede de saúde, facilitando o acesso ao atendimento adequado através de uma experiência simples e acessível.

## 🚀 Sobre o Projeto

O projeto engloba o desenvolvimento de uma solução digital completa e integra diversas áreas:
- **UX (User Experience)**
- **Desenvolvimento Mobile & PWA**
- **Arquitetura Client-Server**
- **Análise de Sistemas**

O ciclo de vida do desenvolvimento passará pela construção de uma solução web inicial até a entrega de um aplicativo móvel completo.

### Pilares do Projeto
- **Acessibilidade:** Design focado em atender todos os públicos.
- **Facilidade de Uso:** Interface intuitiva e focada na experiência do usuário.
- **Integração:** Comunicação fluida entre diferentes sistemas de saúde.
- **Inteligência Artificial:** Aplicação de IA como apoio direto para melhorar a jornada e experiência do paciente.
